# 返还文物交接账

本项目服务跨境返还文物的接收、保管与入藏协作。领域对象分为返还案件、接收批次、器物、器物组成、保管地点和交接事件；“套”可以包含多个单件，但每个单件只能处于一条有效保管链上。

交接状态采用 `拟定`、`待双方签署`、`已生效`、`已撤回`、`已更正`。更正通过新事件引用原事件，不能覆盖已经生效的记录。境外机构时间以原始时区保存，同时记录 UTC 时间。资料样例包括华盛顿批次、纽约批次，以及造像、陶俑、恐龙骨架、鱼类化石和恐龙蛋化石等类别。

运行 `python3 service.py --check` 可检查基础配置；执行 `python3 service.py --port 8000` 后，`/health` 返回服务身份。
